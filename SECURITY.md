# Security policy

Please do not open a public issue containing a credential, participant record,
or an unpatched exploit. Report security concerns privately to
`qzkiyoshi@gmail.com` with the repository name and a minimal reproduction.

Supported code is the current default branch. Do not send real API keys in a
report. Revoke and rotate any credential that may have been disclosed, then
provide only the provider name, approximate time, and redacted prefix.

The maintainers will acknowledge a report when available, assess its impact,
and coordinate a fix before public disclosure. This research prototype is not
a security boundary and must not be used to process confidential text without
an independent security and data-protection review.
